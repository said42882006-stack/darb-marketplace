# OTR — منصة تأجير ونقل

مشروع Next.js 14 (App Router) كامل: واجهة متعددة الصفحات + مصادقة + رفع صور + خرائط جوجل + دفع حقيقي عبر Thawani Pay + إشعارات بريد إلكتروني، مبني على Prisma.

## المميزات

- صفحة رئيسية + صفحة مستقلة لكل قسم، مع فلاتر بحث حقيقية من السيرفر
- **تسجيل دخول / إنشاء حساب** (NextAuth، بريد وكلمة مرور مشفّرة bcrypt)
- **رفع صور** للإعلان (حتى 10 صور) عبر Vercel Blob (أو القرص المحلي أثناء التطوير) مع معاينة مصغّرة
- **تحديد الموقع عبر خرائط جوجل**: بحث بالعنوان (Places Autocomplete) + دبّوس قابل للسحب لضبط الدقة
- **دفع حقيقي عبر Thawani Pay** (بوابة عُمانية، صفحة دفع مستضافة آمنة) لكل من الحجوزات وشراء رصيد النشر والاشتراكات، مع وضع محاكاة تلقائي عند غياب مفتاح فعلي
- **نموذج نشر الإعلانات**: 3 إعلانات مجانية لكل مستخدم، ثم شراء رصيد (إعلانان مقابل 0.400 ر.ع.، متكرر)، أو الاشتراك بباقة شهرية/سنوية لنشر غير محدود طوال مدة الاشتراك
- **صلاحية الإعلان 14 يوماً**: كل إعلان ينتهي تلقائياً بعد أسبوعين من نشره ويختفي من التصفح والبحث (تبقى صفحته متاحة بشارة "منتهي" بدون خيار حجز)
- **صفحة "حسابي"**: تعديل الاسم ورقم الجوال، عرض رصيد النشر أو حالة الاشتراك، وعرض/حذف إعلاناتك الخاصة
- **بريد إلكتروني تلقائي**: ترحيب وتأكيد التسجيل، تأكيد حجز للعميل ولصاحب الإعلان، تأكيد شراء الرصيد، تأكيد تفعيل الاشتراك
- تأكيد البريد الإلكتروني إلزامي بعد التسجيل قبل تفعيل تسجيل الدخول (رابط صالح 24 ساعة، مع خيار إعادة الإرسال)
- **تبديل اللغة (عربي/إنجليزي)**: زر في الهيدر يبدّل اتجاه الصفحة (RTL/LTR) ونصوص الواجهة الرئيسية فوراً

## التشغيل محلياً

```bash
npm install
cp .env.example .env
npx prisma db push       # ينشئ قاعدة بيانات SQLite محلية (dev.db)
npm run db:seed          # يضيف إعلانات تجريبية (اختياري، للتجربة فقط)
npm run dev
```

افتح http://localhost:3000

بدون أي إعداد إضافي، الموقع يعمل كاملاً بالوضع التجريبي: الدفع يُحاكى تلقائياً (نموذج بطاقة وهمي بدل التحويل لـ Thawani)، رفع الصور يعمل فعلياً على القرص المحلي، والبريد الإلكتروني يُطبع في الطرفية بدل إرساله فعلياً.

## إعداد المميزات الحقيقية

### 1) تسجيل الدخول (NextAuth)
```bash
openssl rand -base64 32   # ضع الناتج في NEXTAUTH_SECRET بملف .env
```

### 2) خرائط جوجل
1. أنشئ مشروعاً في [Google Cloud Console](https://console.cloud.google.com/google/maps-apis)
2. فعّل **Maps JavaScript API** و **Places API**
3. أنشئ مفتاح API وضعه في `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`

بدون هذا المفتاح، حقل الموقع يعمل كحقل نصي عادي تلقائياً (بدون كسر الموقع).

### 3) الدفع الحقيقي (Thawani Pay)
1. أنشئ حساب تاجر على [thawani.om](https://thawani.om) (يحتاج مراجعة من فريقهم قبل التفعيل الفعلي)
2. من لوحة التحكم، انسخ **Secret Key** و **Publishable Key**
3. ضعهم في `.env`:
```
THAWANI_SECRET_KEY="rRQ26..."
THAWANI_PUBLISHABLE_KEY="HGvTMLD..."
THAWANI_MODE="test"   # غيّرها إلى "live" بعد التفعيل الفعلي من Thawani
```

آلية العمل: عند الضغط "ادفع"، ينشئ السيرفر جلسة دفع، ويُحوَّل المستخدم لصفحة Thawani المستضافة لإدخال بيانات البطاقة (بيانات البطاقة لا تمر عبر سيرفرنا إطلاقاً — أكثر أماناً وامتثالاً لمعايير PCI). بعد الدفع، يعيد Thawani توجيه المستخدم لـ `/api/pay/callback`، الذي يتحقق من نجاح الدفع فعلياً قبل تفعيل أي شي (إضافة رصيد، تفعيل اشتراك، أو تأكيد حجز).

### 4) البريد الإلكتروني (Resend)
1. أنشئ حساباً مجانياً على [resend.com](https://resend.com)
2. **API Keys** → أنشئ مفتاحاً جديداً وانسخه
3. ضعه في `.env`:
```
RESEND_API_KEY="re_xxxxxxxxxxxxxxxxxxxx"
MAIL_FROM="OTR <onboarding@resend.dev>"
```
بدون توثيق دومين، هذا يرسل فعلياً لكن فقط لبريدك الشخصي (بريد صاحب حساب Resend) — مفيد للاختبار.
للإرسال لأي مستلم فعلياً: **Domains** بلوحة Resend → أضف نطاقك → أضف سجلات DNS → بعد التحقق، غيّر `MAIL_FROM` إلى عنوان على نطاقك.

بديل مجاني بدون دومين (يوصل لأي مستلم، لكن قد يصنَّف Spam أول مرة): اترك `RESEND_API_KEY` فاضياً وعبّي بدلاً منه `SMTP_HOST`/`SMTP_USER`/`SMTP_PASS` بحساب Gmail (App Password) — الكود يستخدم Resend إذا كان مفعّلاً، وإلا يرجع لـ SMTP تلقائياً.

### 5) رفع الصور في الإنتاج (Vercel Blob)
1. من صفحة مشروعك بـ Vercel: تبويب **Storage** → **Create Database** → **Blob** → **Create**
2. Vercel يضيف تلقائياً متغير `BLOB_READ_WRITE_TOKEN` لمشروعك — لا حاجة لأي إعداد يدوي إضافي

الكود يفحص وجود `BLOB_READ_WRITE_TOKEN` تلقائياً: موجود ⇒ يرفع لـ Vercel Blob (يعمل على أي بيئة إنتاج بما فيها Vercel)، غير موجود ⇒ يكتب على القرص المحلي في `/public/uploads` (للتطوير المحلي فقط — لا يعمل على Vercel).

## قاعدة البيانات في الإنتاج

1. أنشئ قاعدة Postgres (Supabase / Neon / Railway)
2. غيّر `provider` في `prisma/schema.prisma` من `sqlite` إلى `postgresql`
3. ضع رابط الاتصال في `DATABASE_URL` بالإنتاج، ثم `npx prisma db push`

## إزالة الإعلانات التجريبية

الإعلانات المزروعة بـ `npm run db:seed` لا تنتمي لأي مستخدم حقيقي (بدون `userId`)، بينما أي إعلان ينشره مستخدم حقيقي عبر الموقع يُسجَّل دائماً بـ `userId`. لهذا يمكن حذف بيانات التجربة بأمان تام دون أي خطر على إعلانات المستخدمين الحقيقية:

```bash
npm run db:clear-demo
```

شغّلها على قاعدة الإنتاج (تأكد `DATABASE_URL` بملف `.env` يشاور على قاعدة الإنتاج وقتها) قبل ما توزّع الرابط للجمهور.

## بنية المشروع

```
app/
  page.tsx                     الصفحة الرئيسية
  category/[slug]/page.tsx     صفحة كل قسم + فلاتر
  listing/[id]/page.tsx        تفاصيل الإعلان + صور + خريطة + الحجز
  post/page.tsx                نشر إعلان (محمي بتسجيل الدخول + مجاني/رصيد/اشتراك)
  pricing/page.tsx             باقات الاشتراك (شهري/سنوي)
  login/ register/ verify/     صفحات المصادقة وتأكيد البريد
  account/page.tsx             إدارة الحساب: البيانات الشخصية + إعلاناتي (عرض/حذف)
  pay/failed/                  صفحة فشل/إلغاء الدفع
  api/listings/                GET (فلاتر) + POST (نشر، يتطلب جلسة ورصيد كافٍ)
  api/upload/                  رفع الصور
  api/pay/create/              إنشاء جلسة دفع (حجز/رصيد/اشتراك) — حقيقي أو محاكاة
  api/pay/callback/            نقطة رجوع Thawani بعد الدفع الحقيقي — يتحقق وينفّذ
  api/pay/mock-confirm/        تنفيذ فوري بوضع المحاكاة (بدون Thawani)
  api/auth/                    NextAuth + التسجيل + التحقق وإعادة الإرسال
components/                    ImageUploader, LocationPicker, PaymentModal...
lib/                           prisma, auth, thawani, fulfill, mailer, constants
prisma/schema.prisma           User, Listing, Subscriber, Booking, PendingPayment
prisma/clear-demo.ts           سكربت حذف الإعلانات التجريبية فقط
```

## خطوات مقترحة لاحقاً

- تنظيف دوري (cron) يحذف الإعلانات المنتهية فعلياً من القاعدة بدل الاكتفاء باستبعادها من العرض
- إشعار بريدي للمستخدم قبل انتهاء إعلانه بيومين لتجديده
- عرض تفاصيل الحجوزات (لا الإعلانات فقط) داخل صفحة "حسابي"
- ضغط/تحسين الصور المرفوعة تلقائياً
- توسيع تبديل اللغة ليغطي بقية النصوص (نماذج النشر مثلاً) — حالياً يغطي الهيدر والفوتر والصفحة الرئيسية والأقسام والباقات فقط
