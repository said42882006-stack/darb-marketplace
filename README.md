# OTR — منصة تأجير ونقل

مشروع Next.js 14 (App Router) كامل: واجهة متعددة الصفحات + مصادقة + رفع صور + خرائط جوجل + دفع اشتراكات حقيقي عبر Thawani Pay + إشعارات بريد إلكتروني، مبني على Prisma.

## المميزات

- **12 قسماً**: منازل، سيارات، شاليهات، منتجعات، شاحنات ونقل عام، نقل نفط ومشتقات، توصيل طرود، مندوب ومشاوير، تاكسي وسائق خاص، دراجات، قوارب، وتأجير عام (لأي شيء آخر يُؤجَّر)
- **فلتر خاص لكل قسم**: كل قسم له خاصية مميزة به (عدد غرف للمنازل، ناقل الحركة للسيارات، نوع الشاحنة، إلخ) — تُختار عند النشر وتظهر كفلتر إضافي بصفحة القسم
- شريط علوي بطبقتين (بار معلومات + بار بحث رئيسي) مستوحى من مواقع الإعلانات المبوبة المعروفة إقليمياً
- صفحة رئيسية + صفحة مستقلة لكل قسم، مع فلاتر بحث حقيقية من السيرفر
- **تسجيل الدخول برقم الجوال** (لا بالبريد) — التسجيل: رقم الجوال أولاً → تأكيد عبر رمز واتساب (Twilio) → إكمال الملف الشخصي (الاسم، كلمة المرور، صورة الحساب، الجنس، تاريخ الميلاد، نوع الحساب شخصي/تجاري، والبريد الإلكتروني اختياري بالكامل)
- **قائمة حساب منسدلة بالهيدر**: رقم الجوال، الرئيسية، إعلاناتي، إعدادات الحساب، الأقسام، تسجيل خروج
- **رفع صور** للإعلان (حتى 10 صور) عبر Vercel Blob (أو القرص المحلي أثناء التطوير) مع معاينة مصغّرة
- **تحديد الموقع عبر خرائط جوجل**: بحث بالعنوان (Places Autocomplete) + دبّوس قابل للسحب لضبط الدقة
- **التواصل مباشر مع المعلن**: زر اتصال وزر واتساب ودردشة داخل الموقع بصفحة كل إعلان — لا يوجد دفع للحجز عبر الموقع، فقط دفع الاشتراك لنشر الإعلانات
- **دردشة داخل الموقع**: محادثات مرتبطة بالإعلان بين المستخدمين، بصفحة "دردشاتي" (`/inbox`)، مع عداد رسائل غير مقروءة بالهيدر. تدعم النصوص والصور والرسائل الصوتية، بخلفية مزخرفة بأيقونات تعكس محتوى الموقع (منازل، سيارات، شاحنات، قوارب...). تعمل بتحديث دوري سريع (polling كل 2.5 ثانية) مع إرسال فوري (Optimistic UI) بدون أي خدمة خارجية
- **دفع اشتراكات حقيقي عبر Thawani Pay** (بوابة عُمانية، صفحة دفع مستضافة آمنة)، مع وضع محاكاة تلقائي عند غياب مفتاح فعلي
- **نموذج نشر الإعلانات**: 3 إعلانات مجانية لكل مستخدم، وبعدها يلزم الاشتراك بباقة شهرية أو سنوية لنشر غير محدود
- **صلاحية الإعلان 14 يوماً**: كل إعلان ينتهي تلقائياً بعد أسبوعين من نشره ويختفي من التصفح والبحث (تبقى صفحته متاحة بشارة "منتهي" بدون خيار تواصل)
- **صفحة "حسابي"**: تعديل البيانات الشخصية كاملة (بما فيها رقم الجوال، بإعادة تأكيد عبر واتساب)، عرض حالة الاشتراك، وعرض/حذف إعلاناتك الخاصة
- **رقم الجوال إلزامي ومؤكَّد عبر واتساب** قبل إنشاء الحساب أصلاً (لا بعده) — رمز من 6 أرقام عبر Twilio، مع خيار "أعد الإرسال"
- **البريد الإلكتروني اختياري بالكامل**: إن أُضيف، يُرسل رابط تأكيد اختياري (24 ساعة) لا يمنع تسجيل الدخول إن لم يُفعَّل — فقط يُستخدم لاحقاً للإشعارات
- **تبديل اللغة (عربي/إنجليزي)**: زر في الهيدر يبدّل اتجاه الصفحة (RTL/LTR) ونصوص الواجهة الرئيسية فوراً

## التشغيل محلياً

```bash
npm install
cp .env.example .env
npx prisma db push       # ينشئ الجداول بقاعدة Postgres المحددة بـ DATABASE_URL
npm run db:seed          # يضيف إعلانات تجريبية تغطي كل الأقسام (اختياري، للتجربة فقط)
npm run dev
```

افتح http://localhost:3000

بدون أي إعداد إضافي، الموقع يعمل كاملاً بالوضع التجريبي: الاشتراك يُحاكى تلقائياً (نموذج بطاقة وهمي بدل التحويل لـ Thawani)، رفع الصور يعمل فعلياً على القرص المحلي، والبريد الإلكتروني يُطبع في الطرفية بدل إرساله فعلياً.

## إعداد المميزات الحقيقية

### 1) تسجيل الدخول (NextAuth)
```bash
openssl rand -base64 32   # ضع الناتج في NEXTAUTH_SECRET بملف .env
```

### 2) خرائط جوجل
1. أنشئ مشروعاً في [Google Cloud Console](https://console.cloud.google.com/google/maps-apis)
2. فعّل **Maps JavaScript API** و **Places API**
3. أنشئ مفتاح API وضعه في `NEXT_PUBLIC_GOOGLE_MAPS_API_KEY`

بدون هذا المفتاح، حقل الموقع يعمل كحقل نصي عادي تلقائياً (بدون كسر الموقع).

### 3) دفع الاشتراكات الحقيقي (Thawani Pay)
1. أنشئ حساب تاجر على [thawani.om](https://thawani.om) (يحتاج مراجعة من فريقهم قبل التفعيل الفعلي)
2. من لوحة التحكم، انسخ **Secret Key** و **Publishable Key**
3. ضعهم في `.env`:
```
THAWANI_SECRET_KEY="rRQ26..."
THAWANI_PUBLISHABLE_KEY="HGvTMLD..."
THAWANI_MODE="test"   # غيّرها إلى "live" بعد التفعيل الفعلي من Thawani
```

آلية العمل: عند الضغط "اشترك"، ينشئ السيرفر جلسة دفع، ويُحوَّل المستخدم لصفحة Thawani المستضافة لإدخال بيانات البطاقة (بيانات البطاقة لا تمر عبر سيرفرنا إطلاقاً — أكثر أماناً وامتثالاً لمعايير PCI). بعد الدفع، يعيد Thawani توجيه المستخدم لـ `/api/pay/callback`، الذي يتحقق من نجاح الدفع فعلياً قبل تفعيل الاشتراك.

### 4) البريد الإلكتروني (Resend)
1. أنشئ حساباً مجانياً على [resend.com](https://resend.com)
2. **API Keys** → أنشئ مفتاحاً جديداً وانسخه
3. ضعه في `.env`:
```
RESEND_API_KEY="re_xxxxxxxxxxxxxxxxxxxx"
MAIL_FROM="OTR <onboarding@resend.dev>"
```
بدون توثيق دومين، هذا يرسل فعلياً لكن فقط لبريدك الشخصي (بريد صاحب حساب Resend) — مفيد للاختبار.
للإرسال لأي مستلم فعلياً: **Domains** بلوحة Resend → أضف نطاقك → أضف سجلات DNS → بعد التحقق، غيّر `MAIL_FROM` إلى عنوان على نطاقك.

بديل مجاني بدون دومين (يوصل لأي مستلم، لكن قد يصنَّف Spam أول مرة): اترك `RESEND_API_KEY` فاضياً وعبّي بدلاً منه `SMTP_HOST`/`SMTP_USER`/`SMTP_PASS` بحساب Gmail (App Password) — الكود يستخدم Resend إذا كان مفعّلاً، وإلا يرجع لـ SMTP تلقائياً.

### 5) تحقق رقم الجوال عبر واتساب (Twilio)
1. أنشئ حساباً على [twilio.com](https://www.twilio.com) وفعّل **WhatsApp Sandbox** (مجاني للاختبار — تحتاج ترسل رسالة انضمام من جوالك للرقم التجريبي مرة واحدة)
2. من Twilio Console، انسخ **Account SID** و **Auth Token**
3. ضعهم في `.env`:
```
TWILIO_ACCOUNT_SID="ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
TWILIO_AUTH_TOKEN="xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
TWILIO_WHATSAPP_FROM="whatsapp:+14155238886"
```
بدون هذي المتغيرات، رمز التحقق يُطبع بسجلات السيرفر بدل إرساله فعلياً (وضع تجريبي آمن). للإنتاج الفعلي لاحقاً، تحتاج رقم واتساب أعمال معتمد من Twilio (مو الـ Sandbox).

> **تنويه لحسابات الاختبار الموجودة مسبقاً:** أي حساب أنشأته قبل هذا التحديث بدون رقم جوال لن يقدر يكمّل التحقق (ما فيه رقم يُرسل له الرمز). إما تضيف رقماً لذلك الحساب مباشرة عبر `npx prisma studio`، أو ببساطة سجّل حساباً تجريبياً جديداً.

### 6) رفع الصور في الإنتاج (Vercel Blob)
1. من صفحة مشروعك بـ Vercel: تبويب **Storage** → **Create Database** → **Blob** → **Create**
2. Vercel يضيف تلقائياً متغير `BLOB_READ_WRITE_TOKEN` لمشروعك — لا حاجة لأي إعداد يدوي إضافي

الكود يفحص وجود `BLOB_READ_WRITE_TOKEN` تلقائياً: موجود ⇒ يرفع لـ Vercel Blob (يعمل على أي بيئة إنتاج بما فيها Vercel)، غير موجود ⇒ يكتب على القرص المحلي في `/public/uploads` (للتطوير المحلي فقط — لا يعمل على Vercel).

## ⚠️ ترقية من نسخة سابقة: تغيير جذري بالمصادقة

هذا التحديث يجعل **رقم الجوال** هو المعرّف الأساسي لتسجيل الدخول (بدل البريد الإلكتروني)، ويصبح `phone` عمود **إجباري وفريد (unique)** بجدول `User`. أي حساب موجود مسبقاً بدون رقم جوال سيمنع `npx prisma db push` من إتمام العملية.

**قبل تشغيل `db push` بعد هذا التحديث:**
- إما تضيف رقم جوال لكل حساب قديم يدوياً عبر `npx prisma studio`
- أو الأسهل بمرحلة الاختبار: احذف كل صفوف جدول `User` القديمة عبر `npx prisma studio` قبل الدفع، وأنشئ حسابات جديدة بعدها بالتدفق الجديد

## قاعدة البيانات في الإنتاج

المشروع مضبوط افتراضياً على Postgres. أنشئ قاعدة (Supabase / Neon / Railway)، ضع رابط الاتصال في `DATABASE_URL`، ثم:
```bash
npx prisma db push
```

## إزالة الإعلانات التجريبية

الإعلانات المزروعة بـ `npm run db:seed` لا تنتمي لأي مستخدم حقيقي (بدون `userId`)، بينما أي إعلان ينشره مستخدم حقيقي عبر الموقع يُسجَّل دائماً بـ `userId`. لهذا يمكن حذف بيانات التجربة بأمان تام دون أي خطر على إعلانات المستخدمين الحقيقية:

```bash
npm run db:clear-demo
```

شغّلها على قاعدة الإنتاج (تأكد `DATABASE_URL` بملف `.env` يشاور على قاعدة الإنتاج وقتها) قبل ما توزّع الرابط للجمهور.

## بنية المشروع

```
app/
  page.tsx                     الصفحة الرئيسية + شبكة الأقسام
  category/[slug]/page.tsx     صفحة كل قسم + فلاتر
  listing/[id]/page.tsx        تفاصيل الإعلان + صور + خريطة + التواصل (اتصال/واتساب)
  post/page.tsx                نشر إعلان (محمي بتسجيل الدخول + مجاني/اشتراك)
  pricing/page.tsx             باقات الاشتراك (شهري/سنوي)
  login/ register/ verify/     صفحات المصادقة وتأكيد البريد
  account/page.tsx             إدارة الحساب: البيانات الشخصية + إعلاناتي (عرض/حذف)
  pay/failed/                  صفحة فشل/إلغاء الدفع
  api/listings/                GET (فلاتر) + POST (نشر، يتطلب جلسة ورصيد مجاني أو اشتراك)
  api/upload/                  رفع الصور
  api/pay/create/              إنشاء جلسة دفع اشتراك — حقيقي أو محاكاة
  api/pay/callback/            نقطة رجوع Thawani بعد الدفع الحقيقي — يتحقق وينفّذ
  api/pay/mock-confirm/        تنفيذ فوري بوضع المحاكاة (بدون Thawani)
  api/auth/                    NextAuth + التسجيل + التحقق وإعادة الإرسال
  api/account/                 تعديل بيانات الحساب
components/                    ImageUploader, LocationPicker, PaymentModal, ContactPanel...
lib/                           prisma, auth, thawani, fulfill, mailer, constants, categoryIcons
prisma/schema.prisma           User, Listing, Subscriber, PendingPayment
prisma/clear-demo.ts           سكربت حذف الإعلانات التجريبية فقط
```

## خطوات مقترحة لاحقاً

- تنظيف دوري (cron) يحذف الإعلانات المنتهية فعلياً من القاعدة بدل الاكتفاء باستبعادها من العرض
- إشعار بريدي للمستخدم قبل انتهاء إعلانه بيومين لتجديده
- ضغط/تحسين الصور المرفوعة تلقائياً
- توسيع تبديل اللغة ليغطي بقية النصوص (نماذج النشر مثلاً) — حالياً يغطي الهيدر والفوتر والصفحة الرئيسية والأقسام والباقات فقط
